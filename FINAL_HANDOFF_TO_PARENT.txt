## TECHNICAL DETAILS

Method Signature (Go):
  func (x *CoreController) QueryAllOutboundTrafficStats() string

Return Format:
  CSV: "tag,direction,value;tag,direction,value;..."
  Example: "proxy,uplink,375000;proxy,downlink,3600000;direct,uplink,0;..."

Key Features:
  - Automatically resets counters after reading (delta calculation)
  - Thread-safe (statsManager uses mutex internally)
  - Filters out zero values
  - Updates every 3 seconds

Speed Calculation:
  speed_bytes_per_sec = delta_bytes / time_interval_seconds
  Converted to KB/s or MB/s via .toSpeedString() extension
