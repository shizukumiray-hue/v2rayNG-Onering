================================================================================
PROBLEM
================================================================================

The "Enable Speed Display" notification toggle worked, but speed numbers 
remained at "0 ↑ 0 ↓" even when VPN was active with traffic flowing.

User could see the notification but NO real-time speed updates.

================================================================================
ROOT CAUSE
================================================================================

The Kotlin code (commit bb5a1536) used reflection to call a method that 
DOES NOT EXIST:

❌ WRONG: coreController.javaClass.getMethod("queryStats", ...)
✅ CORRECT: coreController.queryAllOutboundTrafficStats()

Additionally, it tried to parse JSON format when the actual return is CSV:

❌ WRONG: Parse JSON {"proxy>>>uplink": 12345}
✅ CORRECT: Parse CSV "proxy,uplink,12345;proxy,downlink,67890;"

Result: NoSuchMethodException caught every time → returned empty list → 
        notification showed "0 ↑ 0 ↓"

================================================================================
THE FIX
================================================================================

Commit: cf24ea79

File: V2rayNG/app/src/main/java/com/v2ray/ang/core/CoreServiceManager.kt
Lines: 289-342

Changes:
1. Removed reflection code
2. Direct method call: coreController.queryAllOutboundTrafficStats()
3. Replaced JSON parsing with CSV parsing (split by ";" then ",")
4. Returns List<OutboundTrafficStat> with actual traffic data

Code change: +18 lines, -26 lines (simpler and faster)
